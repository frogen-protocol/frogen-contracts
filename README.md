# FROGEN Contracts

Solidity source code for the FROGEN protocol.

## Publication schedule

Contract source code will be published in this repository following completion 
of the tier-1 security audit. This protects audit integrity by preventing 
speculation about unfinalized code and ensures that what is published matches 
exactly what was audited.

**Target publication:** Pre-TGE, following tier-1 audit completion

**Audit status:** See [frogen-audits](https://github.com/frogen-protocol/frogen-audits)

## What will be published

Upon audit completion, this repository will contain:

- All Phase 1 contracts (FROGEN ERC-20, SmartVest, DynamicStaking, MerkleClaim, 
  VestingManager, ExemptionRegistry, PrizeTimeLock)
- Deployment scripts and configuration
- Hardhat / Foundry test suites
- Etherscan-verified deployment addresses

For the technical specifications underlying these contracts, see 
[frogen-specs](https://github.com/frogen-protocol/frogen-specs).

## Licensing

Contract source will be published under a license that supports source 
transparency while protecting the protocol from immediate competitive forking. 
The specific license terms will be confirmed at publication.
